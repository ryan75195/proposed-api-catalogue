# Proposed API Catalogue

Fifty **proposed, not implemented** API designs across ten categories, published as an open experiment to see which problems developers and AI coding agents actually look for.

Live catalogue: **https://nice-dune-02fdd5103.3.azurestaticapps.net/** — each proposal has an HTML page, a markdown mirror, an `llms.txt` and a downloadable OpenAPI 3.1 spec. None of these APIs exist yet; the specs describe what they would do.

Machine-readable entry points: [`llms.txt`](https://nice-dune-02fdd5103.3.azurestaticapps.net/llms.txt) · [`sitemap.xml`](https://nice-dune-02fdd5103.3.azurestaticapps.net/sitemap.xml) · per-API `openapi.json`.
